# Forest Analysis Plugin

QGIS plugin developed as part of a Master's thesis for the management and spatial analysis of forest-related geospatial data.

## Description

The Forest Analysis Plugin was developed in Python using the PyQGIS API and is designed to support the management, processing and analysis of geospatial data related to forest areas.

The plugin was developed and tested using real geospatial data from the Regional Unit of Rethymno, Crete, Greece.

## Main Functions

1. Preparation of spatial data
2. Quantitative analysis of Forest Map data
3. Spatial comparison of Forest Map, Cadastre and exchangeable land data
4. Search and analysis of land parcels based on KAEK
5. Search and analysis of land parcels by Cadastral Region
6. Search and analysis of land parcels by forest classification

## Technologies

- QGIS
- Python
- PyQGIS API
